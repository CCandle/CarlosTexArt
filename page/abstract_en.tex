\begin{cqtenabstract}[LaTeX template][engineering document][Chinese typesetting]
This document is a lightweight LaTeX template for Chinese scientific papers, lab reports,
engineering reports, and project documents. It is designed for XeLaTeX, biblatex/biber,
GB/T 7714-2025, and VS Code with LaTeX Workshop.

Keywords can be specified as optional arguments of the abstract environment. Up to five keywords are supported.
\end{cqtenabstract}
